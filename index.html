FinTrack

Backend & Full Stack / Gestión Financiera

Plataforma de gestión de finanzas personales para administración de ingresos, gastos, transferencias, cuentas, presupuestos y metas de ahorro con Dashboard interactivo.

CodeClean AI

Full Stack / Auditoría de Código con IA

Herramienta de auditoría frontend que combina análisis estático con inteligencia artificial para evaluar calidad, semántica HTML y accesibilidad (WCAG).

  • Detección de patrones inaccesibles (imágenes sin alt, estilos inline, botones sin aria).
  • Evaluación semántica de estructura HTML y puntuación de calidad.
  • Integración con Groq API y modelo Llama 3 para recomendaciones inteligentes.
  • Motor de análisis local de respaldo (fallback) ante caídas de conexión.
JavaScript Groq API Llama 3 HTML5/CSS3

Noticiasisa

Frontend / Plataforma Editorial Accesible

Plataforma web informativa con arquitectura responsive enfocada en accesibilidad universal y síntesis de voz para lectura automatizada de noticias.

  • Controles interactivos de reproducción, pausa y selección de voces.
  • Implementación de atributos ARIA y estados dinámicos para lectores de pantalla.
