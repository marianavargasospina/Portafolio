### 2. CodeClean — Analizador estático de calidad frontend

Herramienta web que aplica reglas locales para identificar problemas comunes de calidad, semántica y accesibilidad en interfaces HTML. La versión actual utiliza análisis estático basado en reglas; no se presenta como una integración de IA en producción.

- Repositorio: https://github.com/marianavargasospina/CodeClean

- Tecnologías: HTML5, CSS3, JavaScript, Tailwind CSS y Web Speech API.
- Repositorio: https://github.com/marianavargasospina/noticiasisa
